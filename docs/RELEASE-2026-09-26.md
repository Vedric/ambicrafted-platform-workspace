# Delivery assessment — 2026-09-26

Ambicrafted now provides an authenticated local UI and CLI, supervised SRE
analysis, runbook management, read-only MCP integration and a French feminine
voice assistant. The workstation services are running, backed up and restore
tested. The supported scope is one trusted operator on a private local machine.
This delivery does **not** certify an unrestricted, vulnerability-free or
multi-user production platform.

## Operate

From the repository root:

```sh
./plateforme ouvrir
./plateforme --help
./plateforme sante
./plateforme voix statut
```

The user service serves `http://127.0.0.1:8787`; `ouvrir` creates a short-lived,
single-use login ticket without printing it. WSL can launch the Windows browser.
A private password can also be configured interactively. See
[console operations](CONSOLE.md) and [voice setup](VOICE.md).

The specialist graph is sequential and bounded. It coordinates extraction,
triage, investigation and human review; it does not execute remediation or
allow agents to approve each other. Conversation has no tool authority. SQLite
stores workflow state and Qdrant stores documents. No demonstrated requirement
justified introducing another persistent memory database or unrestricted MCP
connectors. See ADR 0010–0012 for the tradeoffs.

### Real integrated acceptance

After the final runtime promotion, all seven integrated checks passed: service
health, speech runtime availability, real speech/transcription round trip,
semantic search, local conversation, approved analysis and refused analysis.
The last short conversation took **0.75 s**, the approved analysis **22.09 s**
and the refused analysis **24.08 s**. These are individual warm-workstation
observations, not service-level guarantees. Both analysis paths preserved the
human gate and rejected a repeated decision.

An additional Chromium run exercised actual MediaRecorder capture using a
synthetic WAV microphone input, real transcription, manual text confirmation,
real model response, real voice playback and stop. It recorded zero JavaScript
errors and only the local API origin as a network destination. This is not a
test of the operator's physical microphone, Windows audio setup or Safari.

The earlier implicit model reasoning setting exhausted the output budget before
producing structured JSON. Explicit local reasoning control fixed the repeated
acceptance cases. The initial failure remains in the evidence; small successful
samples do not establish model reliability across arbitrary incidents.

### Controlled load and recovery

With 16 concurrent HTTP clients, the bounded 12-entry queue accepted exactly
12 of 48 submissions and rejected the rest; 160 authenticated reads completed
consistently with a measured p95 of 57.4 ms. The worker was suspended for this
experiment: it measures the control plane, not GPU throughput. A separate
six-dialogue CPU speech exercise at concurrency two passed.

The final private backup was restored in disposable resources: **86 PostgreSQL
tables, 31 vectors, 6 console analyses and 6 graph checkpoints**. SQLite integrity
checks passed; restored sessions and login tickets were both zero. Snapshots
are individually coherent, not atomic across all databases. No active data was
replaced during this drill. Daily backup/retention timers are enabled.
