## Changes qualified in this update

- The official node exporter image had nine HIGH findings in its compiler and
  Go dependencies. Its derivative builds pinned upstream source using the pinned
  corrected compiler and `golang.org/x/crypto`, preserving the narrow textfile-only
  runtime. The resulting image has zero HIGH/CRITICAL findings in this scan.
- Grafana's PostgreSQL, InfluxDB and Jaeger plugins are updated using complete
  official signed archives. These remove three HIGH inventory findings. OpenTSDB
  also receives its official patch release. Archive hashes, versions and sources
  are recorded in `gateway/images/grafana/plugins-provenance.json`; signed files
  are never edited individually.
- The telemetry API requires the local CLI credential. Browser sessions are
  refused, labels have bounded cardinality and metrics contain no conversation,
  prompt, document, customer path or run identifier. The exporter has no host
  port, Docker socket, credential or host filesystem mount.
- Voice requests use bounded private pipes and operation correlation IDs. Invalid
  framing terminates the worker. Cancellation and idle expiry release its models;
  raw recordings remain transient. Retaining model sessions is not an audio cache.

## Remaining findings

Grafana retains one Apache Thrift finding (`CVE-2026-43871`), one gRPC finding in
the Prometheus plugin (`CVE-2026-84445`), two in the Cloud Monitoring plugin
(`CVE-2026-84304`, `CVE-2026-84445`) and two reported against its Tempo module
(`CVE-2026-21728`, `CVE-2026-28377`). The upstream Grafana release and available
signed plugin versions were checked again. Scanner presence does not establish
that this local configuration reaches a vulnerable execution path, but that
uncertainty is not a dismissal. Upstream patches or an independently qualified
fix and applicability review remain necessary.

The 44 Neo4j findings concern distribution packages; this scan reports no fixed
package version for those occurrences. Keeping Neo4j authenticated and bound to
loopback reduces exposure but does not repair the packages. Replacing its runtime
distribution without qualification would introduce a different unmeasured risk.

Do not expose Grafana, Prometheus, Neo4j or the console through a public listener
to compensate for remote-access inconvenience. The product remains a private,
single-operator workspace. Client scopes in memory are organizational filters,
not tenant authorization. Document extraction guards are not an OS sandbox.
