# Documentation

Ambicrafted is a private, single-operator AI engineering workspace. Public source
does not expose the running application or make its proposals authoritative.
Start with the installation path below, then practise with synthetic inputs
before using confidential material.

and decisions apply to the source and environment they identify. The current
