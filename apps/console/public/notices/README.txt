Third-party component: elkjs 0.12.0

The console uses the unmodified elkjs JavaScript distribution for diagram
layout in a local Web Worker. The upstream package offers EPL-2.0 OR
GPL-3.0-or-later; this distribution uses the Eclipse Public License 2.0
alternative. The license is included alongside this notice as elkjs-LICENSE.txt.

Upstream source and build instructions:
https://github.com/kieler/elkjs/tree/v0.12.0
Exact published package (also contains its license):
https://registry.npmjs.org/elkjs/-/elkjs-0.12.0.tgz
Integrity is pinned in apps/console/package-lock.json.

The project Apache-2.0 license does not replace licenses of third-party

and license notices continue to apply. No changes to the elkjs source are
